# Adversarial Search

An AI assignment project for playing Mancala and evaluating adversarial-search strategies. It includes a game model, heuristic functions, minimax, alpha-beta pruning, move ordering, and experiment runners.

## Requirements

- Python 3.9+

## Run

```bash
python main.py
```

The program compares heuristics and search strategies, runs depth and tournament experiments, and stores generated results under `results/`.
